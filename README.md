# Run Guide:

1. Get the repo cloning link

<img width="524" height="425" alt="image" src="https://github.com/user-attachments/assets/95e5d148-deec-4f0d-a594-5d2fd57259dc" />

2. Run `git clone https://github.com/AvengerFreak/Problem-Solving.git` in the command line.

3. Checkout the java branch by running `git checkout python` in the command line.

4. Navigate to the root directory Problem-Solving and open the Java file you would like to execute.
  
5. Modify the Java module by hardcoding the input
  
6. Then run `javac filename.java` in the command line.
